This one isn't just a project — it's something I built for a friend who was drowning in paperwork. Here's the full story, and everything I put inside the app.

Electron React.js Node.js SQLite HTML / CSS electron-builder

1 Why I Built BKS Agri Mall

So here's how it all started.

BKS Agri Mall is my friend's new startup. When he started out, he was struggling with everything on his own — all the billing, the inventory, the stocks, the taxes, everything by hand. Watching him go through all of that, I thought to myself — why wouldn't we just have one software for all of this?

So I started building this software. From scratch to everything — I built out every single part of it myself. And I made it a free software for him, because that's what I wanted to do for a friend.

100% Free Software
I also added three backups for the data

I knew his data was the most important thing, so I didn't want to rely on just one copy. I built three backups right into the app:

1

Local Storage

First, all the data is saved safely on the shop's own computer.

2

Auto USB Backup

Second, the app auto-detects a USB drive and transfers a copy of the data to it daily.

3

Weekly Email Backup

And third, every week it sends a zip file of all the data straight to my mail.

That way his data is always safe — even if the computer crashes, it still lives on a pen drive and in the inbox. Now let me walk you through everything I built inside the app. 👇

2 Inside the App — Page by Page

Here's a walkthrough of every screen I built, with a real screenshot under each one.

Login Page

The app opens to a secure login screen. Each user (owner / staff) signs in with their credentials, and access to sensitive sections like reports and settings is restricted based on role. This keeps billing data safe on a shared shop computer.

Login & authentication screen

Billing Page

The heart of the app. The owner adds products to a bill, the totals and GST calculate automatically, and a clean, print-ready invoice is generated instantly. Stock is reduced automatically with every sale, so inventory always stays accurate.

Billing & invoice generation

Inventory Page

A complete product catalog where the owner adds items, sets prices, and tracks quantity on hand. The system flags low-stock products so nothing runs out unexpectedly, and every billing transaction updates stock in real time.

Inventory & stock management

Invoices Page

Stores customer details and purchase history, making it easy to look up past bills, track credit/dues, and build a loyal customer base. Repeat customers can be selected instantly during billing.

Customer management

Attendance

A built-in staff attendance module to mark daily present/absent records for employees. This helps the owner track working days directly inside the same software used for billing — no separate register needed.

Staff attendance tracking

Reports & Analytics page

Generates daily, monthly, and custom-range sales reports so the owner can understand revenue, best-selling products, and overall business trends. Reports can be reviewed on screen and printed for record-keeping.

Sales reports & analytics

3 How I Built It

And here's how it all came together under the hood:

  • Designed the UI as a React single-page app, with each module (billing, inventory, attendance, etc.) as its own component.
  • Wrapped the front end in Electron so it runs as a true desktop app with native windows, menus, and printing.
  • Used a local SQLite database so the entire system works 100% offline — critical for a shop with unreliable internet.
  • Built the three-layer backup system — local save, auto USB copy, and a weekly zipped email backup — so the data is never at risk.
  • Wrote the billing logic so stock, totals, and GST update automatically and stay consistent across every screen.
  • Packaged the final build into a Windows installer with electron-builder and shipped it to my friend.
  • Handled real-world delivery too: getting past the Windows SmartScreen warning for an unsigned app and writing simple install steps.
